Return Follower Z · 2026-08-30 · 배경 3D 에셋

주택 블록이 채워지기 시작했습니다

배경 오브젝트를 3D 모델(GLB)로 직접 납품하는 경로가 확립됐고, 하루 만에 주택 5채 · 차 3종 · 나무 4종 · 소품 12종 + 로트 그룹 1개가 나왔습니다. 전부 실측 미터 단위, 같은 팔레트입니다.

1. 무엇이 바뀌었나 — 2D로 굽지 않고 3D를 드립니다

City Block Editor가 3D를 직접 받아 자체 렌더링(Sprite Match · SSAO)하므로, 중간 단계를 없앴습니다.

원래 계획은 3D로 만들고 2D 이미지로 구워 전달하는 것이었습니다. 이제 GLB 파일을 그대로 납품합니다. 카메라가 기울면 옆면이 보이므로 모든 에셋은 탑뷰 메인 + 옆면도 어색하지 않게 만들고, 외곽선·그림자는 에셋에 넣지 않습니다 — 분리는 툴의 AO가, 그림자는 툴이 만듭니다.

모든 에셋은 실측 미터 단위입니다 (주택 용마루 6.0~7.0m · 차 4.8m · 가로수 6.5m). 툴이 미터 단위라 축척 문제 없이 바로 배치됩니다.

2. 1차 결과물 25종

전 에셋이 원작 스타일 레퍼런스 실측 기준(명도·채도·재질 톤)을 자동 측정으로 통과했습니다.

분류에셋비고
주택 5채카툰 주택 1호 + 랜치·방갈로·와이드(테라코타 지붕)·차고형LA 교외 1~1.5층만 선별
차량 3종세단(그레이/레드) + 밴 2종색 변형은 텍스처 교체만
나무 4종마당수 대·중, 소형, 침엽 세장형야자수는 다음 차수
소품 12종피켓/레일 울타리 · 벤치 · 드럼통 · 나무상자 · 잔디깎이 · 정원카트 · 우편함 · 쓰레기통 · STOP 표지판 · 정원석 2굵은 글씨 = 원작에 없던 LA 신규
로트 그룹 1위 에셋 18점을 조립한 주택 1채 프리팹아래 4장

3. 같은 그림체의 비결 — 형태는 사오고, 색은 우리 것

보유 3D 팩에서 형태만 가져오고, 팩의 원래 색·재질은 전부 버립니다.

스타일 레퍼런스(탑다운 일러스트 시리즈)에서 명도·채도·대표색을 픽셀 실측해 합격 기준을 만들어 두었고, 새 에셋은 이 기준으로 자동 측정해 통과해야 완성으로 칩니다. 형태는 팩에서 선별해 반입하거나(주택·나무·소품 대부분), 우편함·표지판처럼 단순한 것은 직접 만듭니다. 그래서 “팩을 섞어 썼는데 전부 같은 그림체”가 됩니다.

사람 손이 들어가는 곳은 형태 선별과 최종 육안 확인뿐입니다 — 하루 25종이 나온 이유입니다.

4. 로트 그룹 — 실제 LA의 배치 수치로

주택 1채 + 주변 세팅을 하나의 그룹으로 묶었습니다. 배치는 감이 아니라 LA 사우스베이(토런스) 위성사진 실측입니다.

실측 배치 수치값
로트 폭17 m
연석 → 파크웨이 잔디 → 보도1.8 + 1.2 m
앞마당 셋백 (보도 → 집)~7.6 m
드라이브웨이 폭3.2 m

이 수치가 곧 맵 블록 규격의 기초값입니다. 로트 변형은 배치표만 바꾸면 나오는 구조라, 주택 5채 × 소품 조합으로 블록을 빠르게 채울 수 있습니다.

5. 프로그래머께 — 확인 요청 3건

GLB·작업 파일은 공유 드라이브 Return_FollowerZ/_scratch/bg/에 있습니다.

★ 그룹 GLB

City Block Editor가 다중 오브젝트 GLB(그룹)를 받나요?

로트 그룹은 22개 오브젝트가 한 GLB에 들어 있습니다. 단일 메시만 받는다면 합쳐서 다시 뽑겠습니다 — 1분 거리입니다.

6. 주의 — 라이선스 확인 전까지는 검증용

형태 소스로 쓴 외부 팩은 상용 게임 사용 가능 여부가 아직 미확인입니다.

확인 전까지 이 에셋들은 툴 검증·스타일 확정용으로만 씁니다. 확인 작업은 다른 외부 소스와 묶어 진행할 예정이고, 형태를 참조해 새로 만드는 대체 경로도 있어 막히지는 않습니다.

2. 파이썬 설치

  1. python.org/downloads 에 들어가 노란 Download Python 버튼을 누릅니다.
  2. 받은 파일을 실행합니다.
  3. ★ 첫 화면 맨 아래의 Add python.exe to PATH 를 반드시 체크합니다. 이걸 놓치면 나중에 “python을 찾을 수 없습니다” 가 뜹니다.
  4. Install Now 를 누르고 끝날 때까지 기다립니다.

⚠️ 체크박스를 놓치셨다면 — 설치 파일을 다시 실행하고 Modify 가 아니라 제거 후 재설치가 가장 빠릅니다. 제거는 설정 → 앱 에서 Python 을 찾아 지우시면 됩니다.

잘 됐는지 확인 — 여기서 “터미널 여는 법” 을 익힙니다

앞으로 계속 쓰게 되므로 이 방법을 기억해 두시면 좋습니다.

  1. 압축을 푼 폴더를 파일 탐색기로 엽니다.
  2. 맨 위 주소창(폴더 경로가 적힌 칸)을 마우스로 한 번 클릭합니다. 경로가 파랗게 선택됩니다.
  3. 거기에 powershell 이라고 덮어써서 입력하고 Enter.
  4. 검거나 파란 창이 뜹니다. 이게 터미널입니다. 여기에 명령을 씁니다.

터미널에 아래를 입력하고 Enter 를 칩니다.

python --version

Python 3.12.x 처럼 숫자가 나오면 성공입니다. (3.10 이상이면 됩니다.)

macOS 를 쓰신다면 — 터미널은 Spotlight(⌘+Space) 에서 터미널 을 검색해 엽니다. 그다음 cd 를 치고 폴더를 창 안으로 끌어다 놓은 뒤 Enter 를 치면 그 폴더로 이동합니다.

3. 도구 설치

준비된 스크립트가 알아서 합니다. 명령 한 줄입니다.

압축 푼 폴더에서 2장의 방법으로 터미널을 열고, 아래를 그대로 붙여넣고 Enter.

powershell -ExecutionPolicy Bypass -File scripts/setup-local.ps1

macOS 는 bash scripts/setup-local.sh 입니다.

1~2분 걸립니다. 화면에 [1/5] 부터 [5/5] 까지 차례로 지나가면 정상입니다. 중간에 영어가 많이 흐르는데 읽지 않으셔도 됩니다.

끝에 노란 글씨로 “API 키가 아직 없습니다” 가 나올 수 있습니다. 정상입니다 — 5장에서 이미지 AI를 연결하면 해결됩니다. 그냥 넘어가세요.

확인

같은 터미널에 아래를 그대로 붙여넣고 Enter.

.\conceptmake.bat list

아직 만든 컨셉이 없다 라고 딱 한 줄 나오면 설치 성공입니다. (아무것도 안 만들었으니 없는 게 맞습니다.)

macOS 는 ./conceptmake list 입니다.

★ 앞의 .\ (점 + 역슬래시)를 빼먹으면 안 됩니다. 빼면 'conceptmake.bat' 용어가 … 인식되지 않습니다 가 납니다. PowerShell 은 지금 폴더에 있는 파일도 .\ 를 붙여야 찾습니다.

그리고 앞에 python 을 붙이지 마세요. python scripts/conceptmake.py 라고 치면 No module named 'numpy' 오류가 납니다. 설치 스크립트가 부품을 .venv 라는 전용 칸에 넣어 두는데, .\conceptmake.bat 이 그 칸을 찾아서 실행해 주기 때문입니다. 이유는 모르셔도 되고, 이 한 줄을 그대로 쓰신다는 것만 기억하시면 됩니다.

4. Claude Code 설치 — 처음 쓰신다는 전제로

명령을 외우지 않고 말로 시키기 위한 창입니다. Claude 를 한 번도 안 써 보셨어도 됩니다. 이 장에 처음 쓰는 사람이 막히는 곳을 다 적었습니다.

Claude Code 가 무엇인가

흔히 아는 ChatGPT 같은 대화창인데, 한 가지가 다릅니다. 보통의 챗봇은 말로 답만 하지만, Claude Code 는 지정한 폴더 안의 파일을 직접 읽고 프로그램을 대신 실행할 수 있습니다. 그래서 “컨셉 뽑아 줘” 라고 하면 실제로 도구가 돌아갑니다.

한국어로 말씀하시면 됩니다. 영어도, 명령어 문법도 필요 없습니다. 친한 동료에게 부탁하듯 쓰시는 것이 가장 잘 통합니다.

설치

  1. claude.com/claude-code 에서 데스크톱 앱을 내려받아 설치합니다.
    같은 페이지에 “터미널에서 설치” 방법도 있는데 그쪽은 별도 프로그램(Node.js)이 더 필요합니다. 데스크톱 앱으로 하세요.
  2. 처음 실행하면 로그인 화면이 뜹니다. 브라우저가 열리면 본인 Claude 계정으로 로그인하고 돌아옵니다.
    1장에서 말씀드린 유료 구독이 여기서 필요합니다. 무료 계정이면 로그인은 되지만 다음이 진행되지 않습니다.
  3. 압축을 푼 그 폴더를 엽니다. “폴더 열기” 또는 “Open folder” 로 C:\fz\... 위치를 지정합니다.
  4. 폴더 안의 규칙 파일을 자동으로 읽습니다. 따로 설정하실 것은 없습니다.

★ 반드시 그 폴더에서 열어야 합니다. 다른 곳에서 열면 도구와 참조 그림을 찾지 못해 “그런 파일이 없다” 가 납니다.

5. 이미지 AI 연결 — Higgsfield

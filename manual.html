Return Follower Z · 캐릭터 생성 도구

설치하고
처음 만들어 보기

순서대로 따라 하시면 됩니다. 처음 한 번만 설치하면 그다음부터는 바로 씁니다. 개발 지식은 필요 없고, 막히는 곳은 8장에 증상별로 정리해 두었습니다.

설치 20~30분 · 캐릭터 1종 뽑는 데 5~10분

0. 이 도구가 하는 일

한 줄로 설명을 적으면 게임에 넣을 캐릭터 그림이 나옵니다.

④까지가 이 도구의 범위입니다. 확정한 탑다운 1장을 그래픽에게 넘기면 부위 분리 · 애니메이션 · 스프라이트 시트는 그쪽에서 만듭니다.

1. 시작하기 전에

아래 넷을 준비합니다. ①②③은 무료이고, ④만 계정이 필요합니다.

준비물무엇시간
① 파이썬도구를 돌리는 프로그램5분
② 받으신 폴더planner-kit.zip 압축 풀기1분
③ Claude Code말로 시키는 창5분
④ 이미지 AI 계정그림을 그리는 쪽 (Higgsfield 등)10분

④ 계정은 아직 정해지지 않았습니다. 새로 만들지, 함께 쓸지 정해지면 알려 드립니다. ①~③까지 먼저 해 두시면 나중에 ④만 붙이면 됩니다.

2. 파이썬 설치

  1. python.org/downloads 에 들어가 노란 Download Python 버튼을 누릅니다.
  2. 받은 파일을 실행합니다.
  3. ★ 첫 화면 맨 아래의 Add python.exe to PATH 를 반드시 체크합니다. 이걸 놓치면 나중에 “python을 찾을 수 없습니다” 가 뜹니다.
  4. Install Now 를 누르고 끝날 때까지 기다립니다.

⚠️ 체크박스를 놓치셨다면 — 설치 파일을 다시 실행하고 Modify 가 아니라 제거 후 재설치가 가장 빠릅니다. 제거는 설정 → 앱 에서 Python 을 찾아 지우시면 됩니다.

잘 됐는지 확인 — 여기서 “터미널 여는 법” 을 익힙니다

앞으로 계속 쓰게 되므로 이 방법을 기억해 두시면 좋습니다.

  1. 압축을 푼 폴더를 파일 탐색기로 엽니다.
  2. 맨 위 주소창(폴더 경로가 적힌 칸)을 마우스로 한 번 클릭합니다. 경로가 파랗게 선택됩니다.
  3. 거기에 powershell 이라고 덮어써서 입력하고 Enter.
  4. 검거나 파란 창이 뜹니다. 이게 터미널입니다. 여기에 명령을 씁니다.

터미널에 아래를 입력하고 Enter 를 칩니다.

python --version

Python 3.12.x 처럼 숫자가 나오면 성공입니다. (3.10 이상이면 됩니다.)

macOS 를 쓰신다면 — 터미널은 Spotlight(⌘+Space) 에서 터미널 을 검색해 엽니다. 그다음 cd 를 치고 폴더를 창 안으로 끌어다 놓은 뒤 Enter 를 치면 그 폴더로 이동합니다.

3. 도구 설치

준비된 스크립트가 알아서 합니다. 명령 한 줄입니다.

압축 푼 폴더에서 2장의 방법으로 터미널을 열고, 아래를 그대로 붙여넣고 Enter.

powershell -ExecutionPolicy Bypass -File scripts/setup-local.ps1

macOS 는 bash scripts/setup-local.sh 입니다.

1~2분 걸립니다. 화면에 [1/5] 부터 [5/5] 까지 차례로 지나가면 정상입니다. 중간에 영어가 많이 흐르는데 읽지 않으셔도 됩니다.

끝에 노란 글씨로 “API 키가 아직 없습니다” 가 나올 수 있습니다. 정상입니다 — 5장에서 이미지 AI를 연결하면 해결됩니다. 그냥 넘어가세요.

확인

python scripts/conceptmake.py list

아직 만든 컨셉이 없다 라고 나오면 설치 성공입니다. (아무것도 안 만들었으니 없는 게 맞습니다.)

4. Claude Code 설치

명령을 외우지 않고 말로 시키기 위한 창입니다.

  1. claude.com/claude-code 에서 내려받아 설치합니다.
  2. 실행한 뒤 압축을 푼 그 폴더를 엽니다. “폴더 열기” 또는 “Open folder” 로 그 위치를 지정하시면 됩니다.
  3. 폴더 안의 규칙 파일을 자동으로 읽습니다. 따로 설정하실 것은 없습니다.

★ 반드시 그 폴더에서 열어야 합니다. 다른 곳에서 열면 도구와 참조 그림을 찾지 못해 “그런 파일이 없다” 가 납니다.

5. 이미지 AI 연결

그림을 실제로 그리는 쪽입니다. Claude 자신은 그림을 그리지 못합니다.

  1. Claude 설정에서 커넥터(또는 MCP) 항목을 엽니다.
  2. 이미지 생성 서비스를 찾아 연결을 누릅니다.
  3. 브라우저가 열리면 본인 계정으로 로그인하고 권한을 허용합니다.
  4. Claude 로 돌아와 연결됨 표시를 확인합니다.

이 단계는 대신 해 드릴 수 없습니다. 각자 계정으로 직접 로그인해야 하는 부분입니다. 막히시면 화면 공유로 같이 하는 편이 빠릅니다 (10장).

6. 처음 캐릭터 만들어 보기

여기서부터는 Claude 에게 한국어로 말하면 됩니다. 명령을 외우실 필요가 없습니다.

① 컨셉 뽑기

Claude 창에 이렇게 씁니다.

LA 도심 갱단 좀비 6종 컨셉 뽑아 줘. 이름은 la-gang 으로.

잠시 뒤 서 있는 캐릭터 6종이 담긴 시트가 4장 나옵니다. 화면에 preview.html 경로가 찍히면 그 파일을 더블클릭해 브라우저로 봅니다.

② 마음에 드는 시트 고르기

4장 중 하나를 고릅니다. “캐릭터가 매력적인가” 만 보시면 됩니다.

3번 시트가 좋아. 그걸로 낱장 잘라 줘.

시트가 유닛 1종씩 낱장으로 갈라집니다.

③ 탑다운으로 바꾸기

게임은 위에서 내려다보는 화면이라, 서 있는 그림을 위에서 본 모습으로 다시 그려야 합니다.

5번 유닛으로 탑다운 뽑아 줘.

후보 4장이 나옵니다. 이번에는 “위에서 본 게 맞는가” 를 봅니다.

맞는 그림

정수리가 보이고, 어깨와 등이 하나의 덩어리처럼 보이고, 팔이 앞으로 뻗어 있고, 다리와 발이 안 보입니다.

틀린 그림

얼굴이 정면으로 보이거나, 가슴·허리·바지·신발이 보이면 카메라가 틀어진 것입니다. 고르지 마세요.

★ 이 판단은 기계가 못 합니다. 실제로 걸러 보려 했지만 틀린 그림이 맞는 그림보다 좋은 점수를 낸 적이 있습니다. 그래서 여러 장 뽑아 사람이 눈으로 고르는 것이 전제입니다. 4장 다 이상하면 “다시 뽑아 줘” 라고 하시면 됩니다.

④ 확정하고 넘기기

2번으로 확정.

확정본이 저장되고, 그래픽에게 넘길 파일 경로가 화면에 찍힙니다. pipeline/concepts/<이름>/picks/ 아래에 있습니다. 그 경로만 알려 주시면 됩니다.
